# AstroGuard

**Astronaut Health Monitoring and Decision Support System**

AstroGuard is a health monitoring prototype designed to support astronaut health assessment during space missions. It brings together physiological measurements, health trend monitoring, warning mechanisms, and an AI-powered assistant.

## Project Overview

AstroGuard aims to help monitor health-related parameters, identify potentially concerning changes, and present relevant information in an understandable way.

The application includes:

- Physiological measurement monitoring
- Health assessment and warning system
- Personal baseline comparisons
- Health trend visualization
- Radiation-related monitoring
- Sleep, fatigue, and stress tracking
- Emergency and measurement guidance
- AI-powered health information assistant
- Mission Control dashboard

## Use of Artificial Intelligence (AI) Tools

AI tools were used during the development of AstroGuard. Their use is disclosed below in accordance with the NASA Space Apps Challenge AI transparency requirements.

### 1. ChatGPT (OpenAI)

ChatGPT was used as a development assistance tool for:

- Explaining programming concepts and Python code.
- Assisting with code development and debugging.
- Suggesting improvements to application structure and functionality.
- Helping prepare and improve user interface text and translations.
- Supporting the organization of technical documentation and project descriptions.
- Helping identify relevant scientific and technical references.

AI-generated suggestions were reviewed and adapted during the development process.

### 2. Google Gemini API

The Google Gemini API is integrated into AstroGuard to provide an AI-powered assistant.

It is used to:
- Generate responses to users' general health-related questions.
- Provide informational guidance.
- Help users understand health-related concepts.

The Gemini assistant is an informational feature. It does not replace professional medical assessment or emergency medical services.

### 3. AI-Assisted Code and Documentation

AI assistance was used during the development of application components, including the health analysis logic, database-related functionality, user interface, and guidance content.

The final implementation was reviewed and integrated by the project developer.

AI-generated suggestions are not treated as authoritative medical evidence. Scientific and medical information is supported by relevant NASA publications and other reliable references where applicable.

### 4. AI-Generated Images, Videos, and Audio

No AI-generated images, videos, or audio are declared as project assets in this version.

If AI-generated visual or audio content is added in a future version, it will be clearly identified in accordance with the competition requirements.

## Scientific References

AstroGuard draws on NASA human-spaceflight standards and relevant external scientific and technical references.

NEWS2, developed by the Royal College of Physicians, is used as a supplementary clinical assessment framework. It is not an official NASA standard and has not been validated as an astronaut in-flight warning system.

NASA publications are used as references for relevant spaceflight health, environmental, and radiation-related topics.

## Important Disclaimer

AstroGuard is an educational and research-oriented prototype developed for the NASA Space Apps Challenge.

It is not a certified medical device, does not provide medical diagnoses, and does not replace professional medical evaluation or official spacecraft medical procedures.
